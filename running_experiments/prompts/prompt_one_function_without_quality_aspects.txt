Your task is to inspect one implementation of a function and decide whether it has a code quality issue.

You will be given:

1. A list of quality aspects to assess, each with a description.
2. The implementation of the function.

Your goal is to decide whether the implementation contains an issue with respect to one or more of the listed quality aspects.

Do not assume that every listed quality aspect is relevant. Select only the quality aspect or aspects that represent the clearest and most meaningful issue in the implementation.

If multiple quality issues are present, choose the one that is most important. Do not list every possible minor issue.

Use the following decision labels:

- Yes: if the implementation has a meaningful issue with respect to one or more of the listed quality aspects.
- No: if the implementation does not have a meaningful issue with respect to the listed quality aspects.

Your answer must include:

1. Issue: one of Yes or No.
2. Quality aspects: the selected quality aspects from the provided list if the answer is Yes. If the answer is No, write “None”.
3. Evidence: if the answer is Yes, provide the specific code-level evidence supporting the issue. If the answer is No, write “None”.

Be precise and avoid overclaiming. Do not report speculative, very minor, or unrelated issues. Do not introduce quality aspects that are not in the provided list.
